# 厨房大作战 · Windows 版

四人本地联机的厨房合作小游戏，Windows 免安装版。

## 下载

到 [Releases](https://github.com/guyan404/kb-release/releases) 页面下载最新 `kitchen-battle-x.y.z.7z`，解压后双击 `厨房大作战.exe`。

## 更新

客户端启动时读取本仓库的 `version.json`，版本号不一致就提示更新。更新包与版本清单分离，出问题可以只改清单里的 version 立即叫停。

## 文件

| 文件 | 说明 |
|---|---|
| `version.json` | 版本清单，客户端检查更新的入口 |
| Releases | 每个版本的安装包，文件名固定为 `kitchen-battle-<版本>.7z` |
